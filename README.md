# Лабораторная работа №3. Каталог авиационных деталей

## Назначение

Пакет aircraft_catalog предназначен для хранения
авиационных деталей. Он поддерживает добавление ("имя каталога".add(...)),
получение данных ("имя каталога".get(...)) и удаление деталей ("имя каталога".remove(...)),
поиск по категории и названию ("имя каталога".find_by_category(...) / ...find_by_name),
сохранение в JSON("имя каталога".save(path)) и загрузку из JSON ("имя каталога".load(path))

## В коде деталь представлена классом AircraftPart, а каталог деталей - классом Catalog.

Class AircraftPart имеет следующие атрибуты:

- item_id - идентификатор детали (строка)
- name - название (строка)
- category - категория (строка)
- year - год выпуска (число целое)
- maker - производитель детали (строка)
- weight - вес детали в кг (число целое/десятичное)

При создании проверяются типы и значения полей. Строки не должны быть пустыми
или состоять только из пробелов. Год должен быть положительным целым числом, 
масса - положительным конечным числом. 

Поля детали неизменны из-за параметра frozen=True. 
Это предотвращает изменение item_id после добавления в каталог
и неизменяемость ID сохраняет его соответствие ключу словаря каталога.

## Операции каталога

- add(item) - добавляет деталь.
- get(item_id) - возвращает деталь по идентификатору.
- remove(item_id) - удаляет деталь по идентификатору.
- find_by_category(category) - возвращает список деталей с точно совпадающей категорией.
- find_by_name(query) - ищет фрагмент названия без учёта регистра.
- len(catalog) - возвращает количество деталей.
- item_id in catalog - проверяет наличие идентификатора.
- Перебор каталога выдаёт детали в порядке добавления.

## Сложность операций

Детали хранятся в словаре, где ключом является item_id.

Получение, добавление, удаление и проверка наличия id выполняются в среднем за O(1). 
Получение кол-ва элементов занимает O(1).

Поиск по категории перебирает все n деталей и занимает O(n). 
Поиск по названию также перебирает все детали.

## Хранение в JSON

Метод save(path) сохраняет каталог в файл.

Файл содержит:
- format_version - версия формата;
- items - список деталей.

Метод load(path) заменяет содержимое каталога данными файла.
Загрузка выполняется через временный каталог. 
Основной каталог изменяется только после проверки всех элементов словаря. 
Если обнаружена ошибка, первоначальное содержимое сохраняется.

## Запуск тестов

Из корневой папки проекта:

`python -m unittest discover -v`

Тесты проверяют создание деталей, основные операции, ошибки каталога, 
поиск, повторную итерацию, сохранение и загрузку JSON, неизвестную версию, 
повреждённый JSON и сохранение исходного состояния при ошибке.
